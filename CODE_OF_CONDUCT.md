# Guide de conduite

## Notre engagement

Nous voulons que travailler sur Otaku Hub soit une expérience agréable et respectueuse pour toute l'équipe, quel que soit le niveau, l'âge ou le parcours de chacun.

## Comportements attendus

- Être respectueux et poli dans les échanges, sur GitHub comme dans le groupe de discussion.
- Accepter les critiques constructives avec calme, et les formuler avec bienveillance.
- Aider les membres qui ont moins d'expérience, sans se moquer de leurs questions.
- Reconnaître le travail de chacun et attribuer le mérite à la bonne personne.
- Respecter les délais annoncés et prévenir tôt en cas de blocage.

## Comportements inacceptables

- Les insultes, les moqueries et les attaques personnelles.
- Le harcèlement, les propos discriminatoires ou offensants.
- Modifier ou supprimer le travail d'un autre membre sans l'en informer.
- Publier des informations privées ou des secrets (mots de passe, clés) dans le dépôt.

## Application

Le responsable du dépôt est chargé de faire respecter ce guide. En cas de souci, il faut d'abord en parler calmement avec la personne concernée. Si le problème continue, il faut le signaler au responsable du dépôt, puis si besoin au coordinateur pédagogique de l'Akieni Academy.

## Portée

Ce guide s'applique à tous les espaces du projet : le dépôt GitHub, les pull requests, les issues, les discussions du groupe et les présentations.
